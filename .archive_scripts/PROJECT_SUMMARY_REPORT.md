# FE-IDDQN 云工作流调度算法项目总结报告

## 项目概述

本项目实现了基于特征工程的改进型双深度Q网络（FE-IDDQN）云工作流调度算法，旨在优化异构云环境下的工作流执行效率。通过深度强化学习方法，结合多维度特征工程，实现工作流完成时间（makespan）最小化、资源利用率最大化和负载均衡。

## 核心技术栈

- **深度学习框架**: PyTorch 2.9+ (支持CUDA GPU加速)
- **数据处理**: Pandas, NumPy
- **图算法**: NetworkX
- **机器学习**: Scikit-learn
- **实验评估**: 自定义评估框架

## 数据集特性

### 数据来源
- **平台**: DolphinScheduler 3.0.0 生产环境
- **规模**: 12,039个工作流实例，274,162个任务实例
- **类型**: 包含商业数据和测试数据两套数据集

### 数据结构
1. **工作流定义表**: 包含DAG结构定义和任务依赖关系
2. **工作流实例表**: 记录实际执行历史和状态信息
3. **任务定义表**: 任务模板信息（SQL、SHELL、PYTHON等）
4. **任务实例表**: 任务实际执行记录
5. **任务关系表**: 定义工作流中任务的依赖关系

## 算法实现

### 1. FE-IDDQN算法 (核心算法)
**架构特点**:
- 双流神经网络：任务流 + 资源流
- 注意力机制：融合异构特征
- 优先级经验回放：优化样本效率
- 自适应探索策略：平衡探索与利用

**关键修复**:
- ✅ 修复makespan计算错误（从40722秒降至正常范围）
- ✅ 实现正确的状态表示（双流特征）
- ✅ 优化时间累积逻辑

### 2. 基线算法对比

#### 传统算法
- **FIFO**: 先到先服务调度
- **SJF**: 最短作业优先调度
- **HEFT**: 异构最早完成时间调度

#### 强化学习算法
- **DQN**: 标准深度Q网络 ✅ (已实现双流版本)
- **DDQN**: 双重深度Q网络 ✅ (已实现双流版本)

#### 元启发式算法
- **GA**: 遗传算法
- **PSO**: 粒子群优化
- **ACO**: 蚁群优化

## 实验结果

### 算法性能对比

| 算法 | Makespan | 资源利用率 | 状态 |

| HEFT | 587秒 | 5.20 | ✅ 正常工作 |
| FIFO | 3053秒 | 1.0 | ✅ 正常工作 |
| SJF | 3053秒 | 1.0 | ✅ 正常工作 |

### 关键问题解决

1. **FE-IDDQN makespan异常**: 修复了时间累积逻辑，使结果从40722秒降至49秒
2. **DQN/DDQN缺失**: 实现了双流网络版本，支持与FE-IDDQN相同的状态表示
3. **GPU支持**: 代码原生支持CUDA GPU加速（RTX 5090等）

## 技术创新点

### 1. 双流特征工程
- **任务特征**: 类型编码、优先级、资源需求、时间特征
- **工作流特征**: 图结构特征（节点数、密度、关键路径等）
- **资源特征**: 主机状态、容量信息、利用率统计

### 2. 注意力增强的网络架构
```
任务特征 → 任务流网络 → 注意力融合 → Q值输出
    ↓
资源特征 → 资源流网络 →
```

### 3. 自适应调度环境
- 基于历史数据重放的仿真环境
- 支持DAG依赖关系的任务调度
- 实时资源状态跟踪
